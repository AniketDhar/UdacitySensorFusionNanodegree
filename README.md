# Udacity Sensor Fusion Nanodegree Projects

This repository collects solutions for the Udacity Sensor Fusion Nanodegree. Each project focuses on integrating perception and estimation techniques for autonomous driving. Highlights include:

- **Camera** – classical computer-vision pipelines (keypoint detection, feature tracking, TTC estimation) using a front-facing camera.
- **Lidar Obstacle Detection** – point cloud processing for ground segmentation, clustering, and bounding-box tracking in urban scenes.
- **Radar** – signal-level processing and CFAR-based object detection on FMCW radar data.
- **Unscented Kalman Filter (UKF)** – sensor-fusion tracker combining lidar and radar measurements to estimate vehicle states along a highway scenario.

Every subdirectory contains its own build instructions and documentation. The projects are self-contained and can be explored independently.
